# Własne formaty plików

[← powrót do README](../README_pl.md)

`user_songs.txt`

```
Tytuł mojego utworu
Cm7 F7 BbMaj7 EbMaj7
```

Tonika utworu jest brana z ostatniego akordu. Jeśli utwór kończy się gdzie indziej, na przykład
na obrocie, podaj tonację po `|` w wierszu tytułu. Oznacza ona tonację utworu w Akordach
i wyznacza stopnie na pasku akordów:

```
Tytuł mojego utworu | Bb
Cm7 F7 BbMaj7 G7 Cm7 F7
```

`user_scales_def.txt`

```
Nazwa mojej skali
1 b2 3 4 5 b6 7
```
