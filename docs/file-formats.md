## 📄 Custom file formats

`user_songs.txt`

```
My Song Title
Cm7 F7 BbMaj7 EbMaj7
```

The tune's home is taken from its last chord. If the tune ends somewhere else, on a turnaround
for example, name the key after a `|` on the title line. It marks the key of the tune in Chords
and sets the degrees in the chord strip:

```
My Song Title | Bb
Cm7 F7 BbMaj7 G7 Cm7 F7
```

`user_scales_def.txt`

```
My Scale Name
1 b2 3 4 5 b6 7
```
